A high-end, multi-page, 3D interactive portfolio website built for a **Robotics Engineer** specializing in Autonomous Mobile Robots (AMRs), Drones (UAVs), Manipulators, and Quadrupeds.

🌐 **Live Website:** [https://Humobot1812.github.io/Portfolio/](https://Humobot1812.github.io/Portfolio/)

---

## 🔥 Key Features

- **🤖 3D Interactive Mech Model (Three.js):** Real-time wireframe robot with dynamic mouse-tracking parallax, glowing core reactor, and rotating orbital energy rings.
- **✨ Connected Particle Grid System:** Full-screen interactive canvas particle network reacting to mouse proximity.
- **🎨 Cyber-Tech Neon Visual Identity:** Deep space purple-black (`#030014`) aesthetic paired with electric cyan (`#00f0ff`), neon purple (`#bf5af2`), and hot magenta (`#ff2d55`) accents.
- **🗂️ Clean Multi-Page Architecture:** Section-swapping Single Page Application (SPA) without hash routing.
- **⚡ Gamified Mission Control System:** XP points, level progression, section badges, and custom cyberpunk boot-up sequence.
- **🎯 3D Perspective Tilt Cards:** Project cards with 3D tilt effects on hover.

## 🚀 Featured Robotics Projects

1. **e-Yantra KrishiCobot (IIT Bombay)** — *Top 10 / 400+ Teams*: Autonomous agricultural cobot with ROS2, SLAM, and UR5 arm pick-and-place manipulation.
2. **ROS2 Differential Drive Robot**: Autonomous navigation, SLAM Toolbox mapping, and AMCL localization pipeline.
3. **Disaster Surveillance Drone (NIDAR Challenge)**: Polygon-based ~75 acre autonomous survey drone with human YOLO detection and failsafes.
4. **Autonomous Survey & Target Detection Drone (SAE Aerothon)**: Target tracking with pixel-to-GPS coordinate conversion.
5. **ESP32-S3 Quadcopter**: Scratch-built quadcopter with custom MOSFET ESC design.
6. **Modular Robotic Arm & Snake Robot**: 5-DOF robotic manipulator and biomimetic serpent locomotion.

## 💻 Local Development

Clone the repository and serve it locally:

```bash
git clone https://github.com/Humobot1812/Portfolio.git
cd Portfolio
python3 -m http.server 8000
```

Open `http://localhost:8000` in your web browser.
