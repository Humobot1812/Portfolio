# Portfolio Website

This repository contains a personal portfolio website for Abhinav Goel.

## Live Site
https://Humobot1812.github.io/Portfolio/

## Files
- `index.html` — main portfolio page
- `profile.jpg`, `eyantra.png`, `Differential_drive_bot.png`, `esp32_drone.jpeg`, `Robotic_arm.jpeg`, `custom_transmitter_receiver.jpeg`, `snake_robot.png`, `hostel_attendance_sysytem.jpeg` — image assets used by the site
- `.gitignore` — ignore editor and temporary files

## Deployment
The site is published with GitHub Pages from the `main` branch root.

## How to update
1. Edit `index.html` or replace image assets.
2. Commit your changes:
   ```bash
   git add index.html README.md
   git commit -m "Update portfolio website"
   git push
   ```
